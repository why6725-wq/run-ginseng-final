# 사주 풀이

생년월일을 넣으면 만세력으로 사주팔자를 계산하고, 그 결과를 AI가 풀어서 설명해 주는 웹사이트입니다. 내 컴퓨터에서 혼자 쓰는 용도로 만들었습니다. 회원가입도 결제도 없습니다.

## 어떻게 동작하나요

두 단계로 나뉩니다. 이 구분이 이 프로젝트에서 가장 중요한 부분입니다.

1. **계산은 코드가 합니다.** 사주팔자, 십신, 대운, 공망은 검증된 만세력 라이브러리가 계산합니다.
2. **해석만 AI가 합니다.** 계산된 결과를 글로 정리해 Claude에게 넘기고, 풀이만 받아옵니다.

AI에게 날짜 계산을 맡기지 않는 이유가 있습니다. 언어 모델은 달력 계산에 약해서, 맡기면 틀린 사주를 그럴듯하게 지어냅니다. 그래서 Claude에게는 도구를 전부 끈 채로 글쓰기만 시킵니다.

## 시작하기

### 1. 준비물

- Node.js 18 이상
- Claude 구독 (Pro, Max, Team, Enterprise 중 하나)

### 2. 설치

```bash
npm install
```

### 3. 로그인 토큰 만들기

터미널에서 아래 명령을 실행합니다.

```bash
claude setup-token
```

브라우저 창이 열리고 로그인을 승인하면, 터미널에 1년짜리 토큰이 찍힙니다. 그 값을 복사해 둡니다.

`claude` 명령이 없다면 먼저 설치합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

### 4. 토큰 넣기

```bash
cp .env.example .env.local
```

`.env.local` 파일을 열어 아래 줄의 주석을 풀고 토큰을 붙여넣습니다.

```
CLAUDE_CODE_OAUTH_TOKEN=여기에_붙여넣기
```

이 파일은 git에 올라가지 않습니다. 토큰은 비밀번호와 같으니 공유하지 마세요.

이 컴퓨터에서 이미 `claude`로 로그인해 두었다면 이 단계를 건너뛰어도 됩니다. 토큰이 없으면 기존 로그인을 그대로 씁니다.

### 5. 실행

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 용어 풀이

처음 보면 낯선 말들을 정리했습니다.

**OAuth** 비밀번호를 넘겨주는 대신 브라우저로 로그인해서 받아오는 출입증입니다. 이 출입증으로 내 구독을 쓸 수 있습니다.

**환경변수** 프로그램이 실행될 때 읽어가는 설정값을 컴퓨터에 미리 적어두는 서랍입니다. `.env.local` 파일이 그 서랍입니다.

**스트리밍(SSE)** 해석문이 다 완성될 때까지 기다리면 1분 넘게 빈 화면을 봐야 합니다. 그래서 서버가 연결을 열어둔 채 글자가 생기는 즉시 조금씩 브라우저로 밀어넣습니다. 타자 치듯 글이 나타나는 게 이 방식입니다.

**진태양시** 우리 시계는 동경 135도를 기준으로 맞춰져 있는데 한국은 그보다 서쪽인 127도 부근입니다. 그래서 시계 시각과 실제 태양 위치가 약 30분 어긋납니다. 시주는 태양 위치로 정하므로 이 차이를 보정해야 정확합니다.

**절기** 입춘, 경칩처럼 태양의 위치로 한 해를 스물넷으로 나눈 마디입니다. 사주에서 해와 달이 바뀌는 기준은 양력 1월 1일도 설날도 아닌 이 절기입니다. 그래서 2월 초에 태어나면 연주가 전년도가 되기도 합니다.

나머지 명리 용어는 화면에서 점선 밑줄 그어진 글자에 마우스를 올리면 설명이 뜹니다.

## 계산에서 신경 쓴 부분

사주 계산에는 함정이 많습니다. 이 사이트는 아래를 모두 처리합니다.

| 항목 | 처리 방식 |
|---|---|
| 절기 기준 월주 | 음력 달이 아니라 입춘, 경칩 등 절기로 해와 달을 나눔 |
| 진태양시 | 출생 지역 경도와 균시차를 반영해 보정 |
| 과거 서머타임 | 1948~1951년, 1955~1960년, 1987~1988년 출생자 자동 보정 |
| 야자시 | 밤 11시~자정 출생의 처리 기준을 세 가지 중에 선택 |
| 출생 시각 모름 | 시주를 비우고 세 기둥으로 해석 |
| 음력 입력 | 윤달 포함해 양력으로 변환 후 계산 |

계산 정확도는 독립적으로 검증했습니다. `scripts/test-saju.ts`를 실행하면 여러 사례의 계산 결과를 확인할 수 있습니다.

```bash
npx tsx scripts/test-saju.ts
```

시중 만세력 앱과도 대조했습니다. 팔자 여덟 글자, 십신, 지장간, 음력 환산, 절기 절입 시각, 대운수와 방향, 세운, 월운 열두 달, 12운성, 12신살, 신살 목록, 연주 기준 공망이 모두 일치했습니다.

## 심화 분석

글자를 뽑는 것만으로는 해석이 겉돕니다. 그래서 글자 사이의 관계까지 계산합니다.

**지장간** 지지 한 글자는 사실 천간 두셋을 품고 있습니다. 표에 함께 보여줍니다.

**합충형파해** 글자끼리 끌어당기거나 부딪치는 관계입니다. 삼합, 반합, 방합, 육합, 천간합과 충, 형, 파, 해를 모두 찾습니다. 이게 중요한 이유가 있습니다. 삼합이 하나 있으면 글자 수로는 하나뿐인 오행이 사주를 통째로 이끌기도 합니다. 개수만 세면 놓칩니다.

**신강신약** 일간이 강한지 약한지를 100점 만점으로 매깁니다. 월지에 가장 큰 점수를 주고, 일간을 돕는 자리의 점수를 모두 더합니다. 61점 이상이면 신강, 40점 미만이면 신약으로 봅니다.

**용신** 억부 기준으로 나에게 이로운 오행을 정합니다. 신강하면 덜어내는 쪽, 신약하면 보태는 쪽입니다. 계절로 본 조후 조언도 함께 보여줍니다.

신강신약과 용신은 유파마다 기준이 다릅니다. 그래서 결과만 내놓지 않고 어느 글자에 몇 점을 줬는지 표로 펼쳐볼 수 있게 했습니다. 동의하지 않으시면 `lib/analysis.ts`의 `POSITION_WEIGHT`를 고치면 됩니다.

여기까지가 뼈대입니다. 아래는 살에 해당하는 참고 항목입니다.

**12운성** 일간이 각 자리에서 갖는 기운의 세기를 사람의 한살이에 빗대 열두 단계로 나눕니다. 장생에서 시작해 건록과 제왕에서 가장 세고 절에서 가장 약해집니다.

**12신살** 연지가 속한 삼합 무리를 기준으로 각 자리가 띠는 성질입니다. 역마, 도화, 화개 같은 것들입니다.

**신살과 길성** 천을귀인, 태극귀인, 문창귀인, 정록, 암록, 금여, 양인살, 홍염살, 낙정관살, 천덕귀인, 월덕귀인, 황은대사, 괴강살, 백호대살, 현침살을 찾습니다. 기준이 분명한 것만 골랐고, 각 항목이 무엇을 기준으로 나왔는지 함께 보여줍니다.

**월운** 올해 열두 달의 월주입니다. 달이 바뀌는 기준도 1일이 아니라 절기입니다.

신살은 참고 항목이라 앞의 신강신약과 용신을 뒤집지 않습니다. AI에게도 겁주는 말투를 쓰지 말고 성질로만 풀라고 지시해 두었습니다.

## 해석 항목

총평, 성격, 직업운, 재물운, 연애운, 결혼운, 건강, 대운 흐름, 올해 운세까지 아홉 가지를 씁니다. 항목을 바꾸려면 `lib/prompt.ts`의 `SECTIONS` 배열을 고치면 됩니다.

AI는 신강신약과 용신을 뼈대로 삼아 아홉 항목을 일관되게 풉니다. 오행 개수만 세어 말하지 않습니다.

## 폴더 구조

```
lib/
  saju.ts     사주 계산. 만세력 라이브러리를 감싼다
  analysis.ts 지장간, 합충, 신강신약, 용신 (해석의 뼈대)
  spirits.ts  12운성, 12신살, 신살과 길성, 연주 공망 (참고 항목)
  terms.ts    명리 용어 사전. 화면과 AI 프롬프트가 함께 쓴다
  prompt.ts   AI에게 보낼 지시문 구성
  ai.ts       Claude 호출. 인증 방식을 바꾸려면 이 파일만 고치면 된다
  cache.ts    같은 사주를 다시 묻지 않도록 결과 저장
  korean.ts   조사 처리 (토가/금이 같은 것)
app/
  page.tsx              화면 전체
  api/saju/route.ts     사주 계산 API (AI 없이 즉시 응답)
  api/interpret/route.ts AI 해석 스트리밍 API
components/
  BirthForm.tsx      생년월일 입력
  SajuTable.tsx      만세력 표
  ElementBar.tsx     오행 분포
  StrengthPanel.tsx  신강신약과 용신
  RelationList.tsx   글자 사이의 관계
  SpiritList.tsx     12운성, 12신살, 신살
  LuckTable.tsx      대운과 세운
  Interpretation.tsx AI 해석문 표시
  Term.tsx           용어 설명 툴팁
```

## 캐시

같은 생년월일시를 다시 넣으면 Claude를 또 부르지 않고 저장해 둔 글을 보여줍니다. 구독 사용량을 아끼기 위해서입니다. 저장 위치는 `.cache/interpretations` 폴더이며 git에는 올라가지 않습니다.

새로 해석받고 싶으면 화면의 다시 풀이 버튼을 누르거나, 이 폴더를 지우면 됩니다.

프롬프트나 계산 항목을 고쳤다면 `lib/cache.ts`의 `PROMPT_VERSION` 숫자를 올려 주세요. 안 올리면 예전 방식으로 쓴 글이 캐시에서 그대로 나와 바뀐 게 없어 보입니다.

## 나중에 남에게 공개하려면

지금 구조는 **혼자 쓰는 용도**입니다. 그대로 공개하면 안 됩니다.

Anthropic 공식 문서는 이렇게 밝히고 있습니다.

> 사전 승인 없이는, Anthropic은 서드파티 개발자가 자사 제품에 claude.ai 로그인이나 요금제 한도를 제공하는 것을 허용하지 않습니다. 여기에는 Claude Agent SDK로 만든 에이전트도 포함됩니다.

내가 내 구독으로 내 컴퓨터에서 쓰는 것은 Claude Code를 쓰는 것과 같아 문제가 없습니다. 하지만 남들이 쓰게 하는 순간 이야기가 달라집니다.

공개하려면 이렇게 바꿔야 합니다.

1. `.env.local`에서 `CLAUDE_CODE_OAUTH_TOKEN`을 지우고 `ANTHROPIC_API_KEY`를 넣습니다. 코드 수정은 필요 없습니다. `lib/ai.ts`가 알아서 API 키를 우선합니다.
2. 요금이 쓴 만큼 청구되므로, 한 사람이 무한정 요청하지 못하게 막아야 합니다.
3. 회원가입과 결제를 붙입니다.

`lib/ai.ts` 한 파일만 AI 호출을 담당하도록 격리해 두었으니, 다른 방식으로 갈아끼우기도 쉽습니다.
